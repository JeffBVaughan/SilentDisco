# SilentDisco

Mobile app (Android first) for running silent disco events: check-in,
headphone inventory, live channel voting, DJ lineup, and later phone-based
audio streaming and Bluetooth LE Audio (Auracast) channels.

Start with [docs/DISCOVERY.md](docs/DISCOVERY.md). It covers the product
options, hardware, audio delivery, architecture, licensing, risks, the
decisions still open, and the roadmap.
